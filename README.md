# CS360

The app that I was asked to develop was meant to be an app that would ne used to track inventory from either a personal level all the way up to a warehouse that way the userbase can include many different types of people looking to use it for similar but possibly not the same exact goal. The UI needed to be simple to use, easy to look at and also flows smoothly between different screens. When it came to the process of actually developing the app I first focused on the actual look and UI of the app first. After this I put the effort into creating the code to get all of the processes running smoothly. Finally I went back and made adjustments between the code and the UI to help them fit together as much as possible. When testing the functions of the app I made sure to choose all of the possible given options when it came to features such as turning notifications on and off, adding many items or attempting to add a negative amount and other various tests.
